# AI hack prompts

The prompt and the steps from every hack on [omerbinsaleem.com](https://www.omerbinsaleem.com/), one file per hack, ready to paste into Claude Code or any agent.

Each hack on the site is a thing a new AI feature let me build that week: the steps I took and the prompt I used. The site has the story and the numbers; this repo has the part you copy.

## How to use one

1. Open the hack's file and read the steps once.
2. Copy the block under "Prompt to copy" into Claude Code, or into any agent that can read your project.
3. Replace the parts in brackets with your own paths or names, if the prompt has any.

New hacks land here the day they go up on the site. Star the repo to get them in your feed.
